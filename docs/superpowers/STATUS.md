**「答题卡诊断」这个模式里第一次真的有答题卡了。** 老师把已批改的答题卡传上来

几分 · 对/半对/错」，每一题挨着原图切片，互校不一致的地方显式标出来，能改判。

新增四个模块：`sheetcut.py`（Ⓢ 抠图，纯几何不调模型）、`sheetread.py`（Ⓑ 读批改，
两遍）、`sheetverdict.py`（Ⓒ 判定，纯函数）、`verdicts.py`（判定值域，只此一份）。

### 探针推翻了三条原设计前提（2026-08-10，方舟 doubao-seed-evolving）

1. **「不要放大」应该是「不要*整张*放大」。** 整页放大 2× 并没有超时（337 秒），
   它的毛病比慢严重得多：把「读不出来」变成了「编一个」—— 选择题 1-4 全答 A
   （真值 D C C B），题 6 把老师红笔写的正确答案当成学生的作答。
   而**裁小块**再放大 3× 是满分，还快 4 倍。
2. **「verdict 直接来自 mark」不成立。** 12(3) 老师打了红勾，给的却是
   `1分(满分2分)`——双选题「选对但不全得一半」。只看勾叉这道题会被记成掌握了。
   判定改成**优先看卷子上印的分数**，`verdict` 多一个 `partial`。
3. **薄弱点从「错的道数/总道数」改成「丢的分/总分」。** 部分给分是常态。

三件原来没记的事实：答题卡第 13 题的小问编号是 (1)(2)**(4)(5)**，和参考答案的
(1)(2)(3)(4) **对不上**（看过原图，不是模型读错）；老师会在选择题旁红笔写正确
答案（白捡的第三份对照）；分数要存 `numeric`，有 7.5 分和 58.5 分。

### 这一轮最隐蔽的一条：题号「精确挂错」

按 `n = 主题号*100+小问号`，答题卡的 (1)(2)(4)(5) → 1301/1302/**1304**/1305，
参考答案的 (1)(2)(3)(4) → 1301/1302/1303/1304。**三条精确等于一个已存在的题号**，
而卡上的 (4) 实际对应答案的 (3)。设计里那道「不许猜一个最近的题号安上去」的防线
**拦不住它**——那条防的是「猜」，这是精确相等。

规矩改成：**某道大题的小问集合与参考答案不完全相等时，整道大题一条都不绑**。

### 顺手堵掉的两条数据毁坏路径（都是既有的，不是步二引入的）

1. **传一份同名 PDF 会把答案卷整卷覆盖掉。** `publish` 是整卷替换，而答案卷的
   小问题号是 1201/1301 这种、PDF 链永远不会产出 → 标准答案、官方解答、知识点
   全删掉。API 层改名 + `store.publish` 底闸，**两个方向都要有**。
2. **`sheet_answers.question_id` 是 `ON DELETE CASCADE`**——删一道题会带走学生
   的作答、原图切片、老师的改判。而「挂不上题」在这个设计里本来就是**正常状态**，
   所以该是 `SET NULL`（解绑）不是 CASCADE（删行）。

### 新增三道门禁

- 每个带 `__main__` 的管线脚本都必须进 `PIPE_RE`（**顺手补上一直漏着的 `stemread`**
  ——Ⓔ 跑的那几分钟里上传闸门是漏的）；排除名单里不许有已经不存在的名字
- **测试里永远不许真调模型**（`conftest.no_real_model`）。这条是踩出来的：
  `run_sheet_pipeline` 扩到整条链的那一刻，两条只想验切图的测试顺着走进了 Ⓑ、
  真的去调了方舟——全量从 9 秒变 175 秒，而且不报错，只是慢
- `verdict` 的值域只留一份（`verdicts.py`），报错文案由清单拼出来

（`kps` 为空既可能是没跑过、也可能是跑了没挂上）。加这个信号是改表，
不该顺手夹带。**动 Ⓔ 的时候一起定**：要么加一列，要么让 Ⓔ 落地后 17 道自然挂上。

### 问题 6 的诊断（`group_option_figures` 只认单行）

选项本身是图的题（「下列四幅电场线图哪个正确」），四张图要分给 A/B/C/D。
`segment.py` 的 `group_option_figures` 只认「**一行 N 个并排**」，认不出
**2×2 网格**，而 2×2 在高考卷里很常见。另外它按 `round(y/12)` 分行也是错的：
记录里 `y` 是图片**底边**，同一行的图往往顶边齐而底边不齐（陕西卷第8题两张并排图
底边差 18，分进了两个桶，顶边却完全相同）。

全库 9 份卷子：这类题 11 道，认出来 5 道、**坏了 6 道**。

坏了之后：`text_quality` 判 degraded → 页面上选项 A/C/D 全空、四张图无标号挂在
题干下面，**读题的人分不出哪张图是哪个选项**；③ 解题只拿到「题干插图1..4」没有
字母，只能靠数数猜对应。

**已核实：陕西卷 q1/q8 两道答案都对**，模型是靠看图内容补回来的（认出 y-t 振动
图像不是选项，从第二张开始数）。但那依赖两件没有保障的事：图的顺序恰好等于阅读
顺序（`ingest.extract_page_images` 遍历 `page.images` **没有排序**，拿的是 PDF
内容流顺序），以及题干图和选项图长得不一样。一旦错位就是整道题全错，而且
**静默** —— 物理推理照样完美，只有字母错；真题 PDF 没有参考答案对不了账，
④b 只检 spec 自洽、⑥ 只检动画，**全链路没有一层看选项字母**。

## 四、踩过的坑（写下来免得重踩）

1. **`stage_of` 加一格必须同时改分支/回填**，否则已完成的卷子集体退回「未完成」、
   进度带永远转。踩过两次（③c、`answers_only`）。
2. **不要把图放大后再送模型。** 同一页 1080×1441 要 57 秒，放大到 1620×2208
   之后 claude CLI 600 秒都回不来。要看清就裁小一块，别整张放大。
3. **JSON 会静默吃掉 LaTeX 反斜杠。** `\t` `\f` `\r` `\b` 都是合法 JSON 转义，
   `json.loads` 会把 `\times` 变成 TAB+"imes"、`\frac` 变成 FF+"rac"。不报错。
   已在 `mathvlm.loads_lenient` 修掉（`bd46b2c`）。
4. **`index.html` 必须 `no-cache`。** 否则前端更新了页面毫无变化，普通刷新也没用 ——
   它里面写着当前那版 JS 的文件名。已修（`ccdbd42`）。
5. **upsert 只更新自己那几列。** `put_answer_question` / `put_stem` / `put_kps`
   三步分工写死，列错一个就会在重跑上游时把下游的产出冲没。
6. **带圈数字/字母不是 Python 合法标识符**，测试函数名里不能写 `③` `Ⓐ`。
7. **子进程的 `print` 是块缓冲**，跑几分钟的脚本不 `flush` 的话外面一个字都看不到，
   跟卡死分不出来。
8. **`.env` 是进程启动时读的，而且是 `setdefault`。** 后端把自己那份快照原样传给
   管线子进程，子进程改不动。已修，但同类问题（模块顶层读环境变量的常量）到处都是，
   改配置之后别只看文件，要看**进程实际解析出来的值**。
9. **代码明明是对的却报 `KeyError` / `AttributeError`，先清 `__pycache__`。**
   traceback 显示的是新源码、跑的可能是旧字节码，两边对不上时人会一直怀疑源码。
10. **逼模型回答，会把诚实的弃权变成自信的错误。**（2026-08-10 实测，同一张图两次）
    提示词不提选择题时，8 道填涂全回 `unreadable` + `conf: low`，一个都没编；
    写了「填涂式的选择题也要」之后答了 6/8，错的两条里有一条把老师红笔写的
    正确答案当成了学生的作答。整页放大 2× 也是同一个病。**读不出就该让它说读不出。**
11. **一条链往后延长的那一刻，先想「哪些既有测试会跟着往下走」。**
    `run_sheet_pipeline` 从「只到 Ⓢ」扩到整条链，两条只想验切图的测试顺着走进了
    Ⓑ、**真的去调了方舟**——全量从 9 秒变 175 秒。它不报错，只是慢。
    已配 `conftest.no_real_model` 挡住（挡的是出网那一层，不是 `ask_raw` 本身）。
12. **「不许猜」这类防线拦不住「精确相等」。** 答题卡第 13 题印的小问编号是
    (1)(2)(4)(5)，参考答案是 (1)(2)(3)(4)——按 `主题号*100+小问号` 算，
    有三条**精确等于**一个已存在的题号，而含义是错位的。比集合，别比单条。
13. **写死的判据要拿全部真材料跑一遍再信。** 这一轮我自己写下又被材料证伪三条：
    Ⓢ 的「亮带 ≥60% 就算整页」（干净答题卡只有 48%）、Ⓑ 的「相邻题挨太近就合并」
    （真 y 值一跑整页并成一条）、「Σ 对总分能判读串」（两题得分对调总和不变）。

页面调一条那个进程里根本不存在的路由，FastAPI 回一句默认的 `Not Found`

页面上一屏「打不开这份卷子的诊断结果 Not Found」，而代码和测试都是对的。

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8712/api/papers/x/sheets

```

