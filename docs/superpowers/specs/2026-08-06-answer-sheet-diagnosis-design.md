## 材料长什么样（这一节是事实，不是设计）

老师给的一组材料（`Desktop/试卷+答题卡/`，6 张图）：

| 张数 | 内容 |
|---|---|
| 2 | 手机截图（某考试报告 app），中间嵌着**已批改**的答题卡照片 |
| 4 | **参考答案**印刷页，含完整解答过程 |

**没有题目。**

答题卡上有：红勾红叉、每小题得分（「7.5（满分12分）」）、总分 58.5、学生姓名班级座号。
手写作答放大后可读。逐题对过参考答案，红勾红叉与标准答案**完全一致**：

| 题 | 学生写的 | 参考答案 | 老师批的 |
|---|---|---|---|
| 9 | 不变 / 17190 | 不变 / 17190 | ✓ ✓ |
| 11 | BIL / MQ | **2BIL / MP** | ✗ ✗ |
| 12(1) | 170 / B | 170 / **A** | ✓ ✗ |
| 13(1) | AC | **BC** | ✗ |

参考答案里**法则名字直接写着**：「由盖-吕萨克定律」「E=BLv₀」「qvB=mv²/r」「由动量定理得」。
这是本设计的关键依据 —— **知识点可以从解答过程挂，不需要题干**。

## 背景

现有产品把试卷 PDF 变成「逐题讲解 + 物理动画」，服务对象是老师。但它回答不了老师真正
要问的下一个问题：**我这个学生哪里不行、该补什么**。

学校的阅卷系统已经把对错判好了。缺的不是判分，是**把错题聚合成知识点、再落到怎么补**。

## 目标

- 老师传一份**参考答案**和一份**已批改的答题卡**，得到一份诊断报告。
- 报告逐题给出对/错，每一题都能当场对照答题卡上的原图。
- 报告给出**薄弱知识点**，知识点来自受控词表，能跨题聚合。
- 报告给出**怎么提升**，每条建议都落到具体题号，接参考答案里的官方解答过程。
- 系统按标准答案判一遍，与老师的批改互校，**不一致就标出来**。

## 非目标

- **不判分数 —— 但要读卷子上印的分数。**（2026-08-10 澄清）系统一分不算：
  每小问的「X分(满分Y分)」和总分都印在答题卡上，Ⓑ 只是把它们**转写**下来。
  转写下来的分数有三个用处：判「半对」、按丢分排薄弱点、拿 Σ得分对总分查有没有读串。
  仍然不做的是**排名**和**跨学生比较**。
- **不做自动阅卷。** 对错以**老师的批改**为准。系统那一遍只用来互校，不当判据。
- **不读手写推导过程。** 只认每题的最终作答。「错在哪一步」不在范围内。
- **没有动画，也不做 AI 讲解。** 官方参考答案里的解答过程就是讲解。
- **不做班级、不做学生账号。** 一次一份答题卡、一个学生。
- **不改 `segment.py` / `anchors.py` / `ingest.py`。** 这条链根本走不到它们。

## 关键决策

| 决策 | 取舍 |
|---|---|
| 对错以**老师的批改**为准 | 学校阅卷系统已经判好，比任何模型都准。原设计最大的风险（自动判错凭空造出假的薄弱知识点）直接消失 |
| 判定优先看**卷子上印的分数**，不是勾叉 | 2026-08-10 探针：12(3) 老师打了勾却只给 1分(满分2分)。只看勾叉会把「半对」记成掌握了，而双选题「选对但不全得一半」是印在卷子上的规则，不是边角情况 |
| 薄弱点按**丢分率**排，不按错题道数 | 部分给分是常态，按道数算的话「半对」要么算整道错、要么算全对，两种都撒谎；而且一个 1 分的空和一道 16 分的大题在道数口径下一样重 |
| 系统仍按标准答案判一遍 | 只用来**跟老师的批改互校**。两边不一致说明有一方错了，标出来让人看 —— 白捡的红绿灯，不额外花钱 |
| 知识点从**参考答案的解答过程**挂 | 没有题干。而解答过程里直接写着法则名字，比题干更有信息量（期一实测：一道「小球从斜面滑下」看题干像运动学，看解法才知道考动能定理） |
| 仍然读手写作答 | 页面要能说「你写的是 BIL，标准答案是 2BIL」。也是互校的一边 |
| 复用 `papers` + `questions`，`stem` 留空 | 归属、删除级联、资产存储、页面路由全都白拿。**老师哪天补传了题目，直接填进 `stem` 就行**，不用搬数据 |
| 从手机截图里抠答题卡 | 材料是截图不是照片，带状态栏和按钮，答题卡只占中间一条。这是新增的一步 |
| 知识点用内置受控词表 | 名字统一才能聚合。期一已经做完（15 章 154 条） |
| 不引 sympy | 期一已定：它解析带单位带下标的 LaTeX 会**静默**判错 |

## 架构

```
参考答案图 ─→ Ⓟ pages ─→ Ⓐ 读参考答案 ─→ 题号 · 标准答案 · 解答过程
                                              │        ↑ 权威题号清单
题目图     ─→ Ⓟ pages ─→ Ⓔ 读题干      ─→ 题号 · 题干 ┘
                                              │
                                              ├─→ ③c 挂知识点（题干 + 解答过程）
                                              │
已批改答题卡 ─→ Ⓟ pages ─→ Ⓢ 抠出答题卡 ─→ Ⓑ 读批改 ─→ 题号 · 学生作答 · 勾/叉
                                                            │
                                              Ⓒ 判定（老师批改为准 + 系统互校）
                                                            │
                                                    Ⓓ 薄弱知识点 + 怎么提升
```

**Ⓔ 比原设计里的 `imgdoc.py` 简单得多。** 原来要从图片造出 `doc.json` 再交给
②`segment.py` 切题；现在**题号清单由 Ⓐ 给出**（参考答案上的题号是权威的），
Ⓔ 只需按题号把题干填进去：不用切题、不用坐标、不用插图归属、不碰 `anchors.py`。

**Ⓔ 的对账是白捡的**：读出来的题号必须是 Ⓐ 那份清单的子集。多出来的题号说明
读错了，当场就能发现 —— 这是原设计里「本题共 N 小题」那道防线的等价物。

**现有的 ①②③④⑤ 一个都不进。** 没有题干，切不了题、解不了题、写不了断言、做不了动画。
这条链与试卷侧那条链**只共用底层**：`pages.py`、`kp.py`、`grade.py`、`store`、`assets`、账号。

期一做的三件事**正好就是这条链要的**，一点没白做：
`questions.kps` / `ref_answer` / `ref_answer_src` 三列、`kp_seed.json` 词表、`grade.judge` 判等。

## 数据模型

```sql
-- 只有参考答案、没有题目的「卷子」。stem 留空，source_kind 标出来。
-- 老师补传题目时直接填 stem，不用搬数据
ALTER TABLE papers ADD COLUMN IF NOT EXISTS source_kind text NOT NULL DEFAULT 'pdf';
--   pdf           走 ①②③ 的完整试卷（现有的）
--   answers_only  只有参考答案（本期新增）

-- 参考答案里的解答过程。ref_answer 是最终答案（期一已有），这一列是过程。
-- 「怎么提升」直接展示它 —— 官方的，比 AI 解出来的可信
ALTER TABLE questions ADD COLUMN IF NOT EXISTS ref_solution text;

-- 答题卡两张表见「答题卡侧」。sheet_answers 相对期二计划的改动（2026-08-10 探针后）：
ALTER TABLE sheet_answers ADD COLUMN IF NOT EXISTS mark_raw   text;   -- 模型读到的批改符号原文
ALTER TABLE sheet_answers ADD COLUMN IF NOT EXISTS score_got  numeric;-- 卷子上印的得分
ALTER TABLE sheet_answers ADD COLUMN IF NOT EXISTS score_full numeric;-- 卷子上印的满分
ALTER TABLE sheet_answers ADD COLUMN IF NOT EXISTS teacher_red text;  -- 老师红笔写在旁边的正确答案
--   verdict     多一个值 'partial'（0 < got < full）
--   verdict_by  多两个值 'teacher_score'（照分数判，优先）/ 'teacher_mark'（照勾叉判）

-- 卷子上印的总分。Ⓑ 读完拿它对 Σscore_got —— 这条链唯一一次性判「有没有读串」的判据
ALTER TABLE answer_sheets ADD COLUMN IF NOT EXISTS total_score numeric;
```

**分数存 `numeric` 不存 `int`**：实测有 `7.5分(满分12分)`，总分 `58.5`。
存整数会**静默**截断成 7 和 58，而丢分率是拿它算的。

**`answer_sheets` / `sheet_answers` 两张表已经建好**（期二 Task 3，commit `bfa38c5`），
结构基本不动，只加 `mark_raw` 一列、`verdict_by` 多认一个值。

**没有 `state` 列**，有意为之：进度由 `stage_of` 从库里的计数反推。

**`stage_of` 必须按 `source_kind` 分支。** `answers_only` 的卷子 `solutions`/`specs`/`scenes`
永远是 0，不分支的话进度带永远转、`done` 永远是 false。**期一加 ③c 那一格时已经踩过一次
一模一样的坑**，这次提前写明。

## 参考答案侧

### Ⓐ 读参考答案

参考答案是**印刷体、版面干净**，比答题卡好读得多。逐页 VLM 转写，输出：

```json
[{"n": "11", "answer": "2BIL / MP", "solution": "由安培力公式 F=BIL…", "points": 3}]
```

三条约束：

1. **题号必须是图上真实认出来的**，不许按顺序编。小问写成 `12(1)` 这种形式。
2. `answer` 是**最终答案**，`solution` 是过程。分开存 —— 判对错拿前者，展示拿后者。
3. 认不出的题**整条丢掉**，不留半条。宁可少一道题，不要一道错的标准答案 ——
   错的标准答案会让做对的学生被判错，凭空造出一个假的薄弱知识点。

写进 `questions`：`n`、`ref_answer`、`ref_solution`、`ref_answer_src='answer_file'`，
`stem` 留空。

### Ⓔ 读题干

**为什么需要它：实测发现参考答案只有大题有详解。**

跑 Ⓐ 读这份材料的第 1 页，20 条全对，但 `solution` 那一列 1-13 题全是空 ——
参考答案的版式就是这样：选择题给一张答案表（`D C C B`），填空题给答案
（`不变 / 17190`），**只有大题才有详解**。4 页参考答案里，详解只覆盖 14、15、16 三道。

一个孤零零的「D」推不出这道题考什么。没有题干的话，**13 道题（含全部 8 道选择题）
挂不上知识点**，而选择题恰恰是诊断信号最密的地方。所以题目必须传。

输入题目图，按 Ⓐ 给出的题号清单填 `stem`：

```json
[{"n": "6", "stem": "如图所示，两平行金属板…（ ）", "options": ["A. …", "B. …"]}]
```

三条约束：

1. **题号必须在 Ⓐ 的清单里。** 多出来的一律丢掉并告警 —— 那说明读错了。
   这是白捡的对账，等价于原设计里「本题共 N 小题」那道防线。
2. **不裁插图。** 物理题常带图，但知识点标注用题干文字就够；要看图就看原页图。
   裁图要坐标，而这条链没有坐标 —— 硬做会引入一个「裁歪了没人看得见」的错。
3. 认不出的题**留空**，不编。页面上写「这道题的题干没读出来」。

### ③c 挂知识点（复用期一，只换输入）

`kpmark.py` 现在的输入是「题干 + ③ 的解法」。这条链改成「题干（Ⓔ）+ 官方解答
（Ⓐ）」，两样有一样就能挂。**其余一个字不改** —— 词表、`keep()` 的过滤规则、
最多 3 个、挂不上留空，全部照旧。

## 答题卡侧

### Ⓢ 从手机截图里抠出答题卡

材料是 app 截图：顶部状态栏和「考试报告」标题栏、底部「我的错题」按钮，
答题卡本身只占中间**一条亮带**，其余部分被 app 压暗了。

**做法改了：先用几何切，不叫模型。**（2026-08-10 探针，见文末）

原设计是「VLM 给框 → 裁」。实测那条亮带用纯代码就能精确找到，而且**两张截图
一模一样地准**：按行平均亮度取最长的连续亮段 → `y=919..1669`（高 750，与本节
原先估的 1080×736 一致）；再在左右中点附近按列平均亮度找最暗的一列，
就是两页之间那道缝 → `x≈540`，切成左右两页。

不叫模型的理由不是省钱，是**这一步的失败必须看得见**。几何切出来的框可以当场
检查（宽高比、亮度、有没有找到定位黑块），模型给的框错了没有判据。

**但几何回答不了「这张是不是截图」。** 同一套判据拿去跑整页扫描件会假阳性 ——
参考答案那 4 张整页都是亮的，照样能切出一条「最亮带」。所以：

- 亮带高度 ≥ 整图 60% → 判定这张**本来就是整页**，不裁，原样往下走
- 亮带太扁（高 < 整图 10%）或宽高比离谱 → **失败**，明说「没在这张图里找到答题卡」

**抠不出来不许硬跑。** 拿一张带着状态栏的图去读题号，读出来的东西没人能信。

### Ⓑ 读批改结果

**一页一次调用，而且分区读 —— 不是整页读一遍。**（2026-08-10 探针实测，见文末）

整页读一遍这条路验过了，它在两处**必然**丢东西：选择题的填涂 8 道全认不出来
（模型自己标 `conf: low`，是老实的），得分标注 10 条错 2 条。而把同一块裁出来
单独放大、配一段说明版面的提示词，两样都是**满分**，还快 4 倍。

所以 Ⓑ 是三个提示词，各读各的：

| 读什么 | 喂什么 | 实测 |
|---|---|---|
| **Ⓑ1 选择题填涂** | 选择题区裁出来放大 3× | 8/8，59 秒 |
| **Ⓑ2 非选择题作答 + 批改符号** | 整页原分辨率（540×750） | 作答 10/10、符号 10/10，235 秒 |
| **Ⓑ3 得分标注** | 得分最密的那块裁出来放大 3× | 8/8，23 秒 |

Ⓑ1 出 `{n, filled, mark, red, conf}`。`filled` 是学生涂黑的字母，`red` 是老师
用红笔**写在旁边的字**（通常是正确答案）—— 这两样必须分开问，合着问的时候模型
会把老师写的 `BC` 当成学生的作答报回来（整页放大 2× 那一版就是这么错的）。

Ⓑ2 出 `{n, answer, mark, conf}`。`answer` 原样转写，空着 `blank`、认不出
`unreadable`；`mark` 是 `right`/`wrong`/`half`/`none`。

Ⓑ3 出 `{n, got, full, raw, conf}`，**一个小问可能有两条**（该题两个空各判各的）。

**题号必须真实认出**，看不清写 `null` 加位置描述 —— 防串题的主要手段。

拿到框之后**当场裁出小图存进 `assets`**。原图切片是这个功能唯一的红绿灯，
它必须和判定一起落库 —— 页面图可能已经被清理。

#### 读完必须对总分

答题卡左上角印着这次的**总分**（实测 `58.5`）。Ⓑ 读完把所有 `got` 加起来，
**对不上总分就说出来**。

这是白捡的端到端校验，而且是这条链上唯一一条能一次性判「整页有没有读串」的判据：
逐题看都像对的，加起来差 2 分，说明某处漏了一题或多读了一条。实测人工照着卷子
逐题读一遍，加起来正好 58.5 —— 判据本身站得住。

对不上**不失败**，警告并把逐题得分列出来让人对。硬失败会把一份 25/26 题都对的
结果整个扔掉，那比带着警告交出去糟得多。

### Ⓒ 判定

**对错以老师的批改为准，而且优先看分数、不是看勾叉。**（2026-08-10 改）

原设计写的是「`verdict` 直接来自 `mark`」，四个值 `right/wrong/blank/unsure`。
探针推翻了它：卷子上 **12(3) 老师打的是红勾，给的是 `1分(满分2分)`** ——
标准答案 `AB`，学生只写了 `A`，双项选择题「选对但不全得一半」。红勾在这里的
意思是「这行判过了」，不是「全对」。只看勾叉，这道题会被记成掌握了。

而这**不是边角情况**：双选题占 24 分，「选对但不全得 3 分」是印在卷子上的
评分规则；15 题也是 `7.5分(满分12分)`。部分给分是这份材料的常态。

所以判定的优先级是：

| 顺序 | 依据 | `verdict_by` |
|---|---|---|
| 1 | 卷子上印的得分（`got`/`full`） | `teacher_score` |
| 2 | 读不到得分时，退回红勾红叉 | `teacher_mark` |
| 3 | 两样都没有 | `unsure` |

`verdict` 由得分推出来，多一个值：

| verdict | 什么时候 | 进薄弱统计吗 |
|---|---|---|
| `right` | `got == full` | 进分母 |
| **`partial`** | `0 < got < full` | **进分母，按丢的分进分子** |
| `wrong` | `got == 0` 且有作答 | 进分子和分母 |
| `blank` | 该题没有作答 | **都不进** |
| `unsure` | 分数和符号都读不出，或题号挂不上参考答案 | **都不进**，报告里单独列 |

#### 题号挂不上是**真会发生**的，不是防御性假设

实测：答题卡第 13 题印的小问编号是 **(1)(2)(4)(5)**，参考答案上是 **(1)(2)(3)(4)**。
我看过原图，不是模型读错 —— 两份材料本身就对不上。

`sheet_answers.question_id` 可空这条设计因此是必需的，而且**不许猜一个最近的
题号安上去**。这四条按满分序列（2/1/2/1）恰好能一一对上，但那是这一份材料的
巧合，不是判据。页面上单独列出来让老师认，比悄悄对错一条强。

#### 互校（白捡的红绿灯）

拿学生作答与标准答案跑一遍 `grade.judge`，跟老师的判定对。

| 系统判 | 老师判 | 怎么办 |
|---|---|---|
| 一致 | | 什么都不做 |
| 不一致 | | **页面标出来**：要么读错了学生的作答，要么参考答案抽错了，要么老师批错了 |
| 系统判不了 | | 不算异常。`grade.judge` 回 `None` 是常态（长解答题） |

**`partial` 不算不一致。** `grade.judge("A", "AB")` 回 `wrong`，老师给的是
`partial` —— 这不是矛盾，是代码档判等本来就没有「部分对」这个档位。
把它算成异常的话，每道双选半对题都会冒一条假警告，真正的异常会被淹掉。

老师在选择题旁边**红笔写的正确答案**（实测题 6 写 `BC`、题 8 写 `AC`）是第三份
对照：它跟参考答案对不上的话，说明 Ⓐ 那一栏抽错了。同样只报，不改数据。

**不一致时一律以老师为准，但必须让人看见。** 这一条同时给 Ⓐ 和 Ⓑ 加了一层校验，
而且一分钱不花 —— 三份数据都已经在库里。

### Ⓓ 诊断

**薄弱点按丢分率排**：`该知识点上丢的分 / 该知识点在这份卷子上的总分`。
（2026-08-10 定，取代原先的「错的道数 / 总道数」）

换成分数的两个理由都来自实测：卷子上**每小问都印着 `X分(满分Y分)`**，裁小块
读出来 8/8 全对，这份数据白摆着；而**部分给分是常态**（12(3) 半对、15 题
7.5/12），按道数算的话「半对」要么算整整一道错、要么算全对，两种都是撒谎。

按分算还顺带解决了一个原设计没提的问题：一个 1 分的空和一道 16 分的大题在
「道数」口径下一样重，而老师心里显然不是这么算的。

- `blank` 和 `unsure` 既不进分子也不进分母（它们的满分也不进）
- 某知识点在这份卷子上总分很低（≤ 2 分）且丢光了 → 标「只考了 2 分，样本不足」，
  不让一个 1 分的空冲到榜首

**「怎么提升」定死结构**，每个薄弱知识点下挂**已经在库里**的东西：

1. 这次错的那几道题 —— 学生作答原图切片 + 标准答案
2. **官方解答过程**（`ref_solution`）—— 这是讲解，而且比 AI 解出来的可信

模型只负责最后一小段：把这几道题串起来说一句「你这几道都栽在同一处……」。
**这段话里必须出现具体题号，没有题号的建议直接丢掉重生成。**

六条硬约束：

- **原图切片必须挨着判定**，不能藏进二级页面。老师一眼能校对是唯一的红绿灯
- **`verdict_by` 要显示**（照分数判 / 照勾叉判 / 老师改判）
- **互校不一致的题必须显式标出来**，不能只在后台记一笔
- **改判后诊断标为过期，不自动重跑**；配「重新诊断」按钮
- **分数要跟判定一起显示**（`1 分（满分 2 分）`）。只显示「半对」而不给分，
  老师没法核对，而这一栏的全部可信度来自「能对着原图核对」
- **Σ得分对不上总分时页面要说**，不能只在日志里记一笔 —— 那说明有题读串了

**「半对」在逐题速览里用 `◐`，不混进 ✓ 也不混进 ✗。** 归到 ✓ 会让老师以为
这块掌握了，归到 ✗ 会让「一分没得」和「差一点」看起来一样严重。

## 失败处理

**缺一条数据就说缺这一条，不要让整份报告消失**；反过来，读不出任何东西就得老实失败。

| 情况 | 处理 |
|---|---|
| 传的不是 PDF/图片 | 400，当场拒 |
| 截图里找不到答题卡 | **失败**，提示裁好再传 |
| 答题卡一道题都没读出来 | **失败**，提示重拍 |
| 参考答案一道题都没读出来 | **失败** —— 没有标准答案，整个诊断没有地基 |
| 参考答案 16 题、答题卡只认出 9 题 | **不失败**，警告并列出缺哪几题 |
| 答题卡上的题号参考答案里没有 | **不失败**，单独列出来，不挂（实测第 13 题就是这样） |
| 得分标注读不出，但有勾叉 | 退回 `teacher_mark` 判定，页面标出「这道题只有勾叉、没有分数」 |
| 得分与勾叉都读不出 | 该题 `unsure`，单独列，不算错 |
| Σ得分对不上卷子印的总分 | **不失败**，页面警告并列出逐题得分让人对 —— 硬失败会把 25/26 题都对的结果整个扔掉 |
| 卷子上读不到总分 | **不失败**，跳过这条校验，页面注明「没能对总分」 |
| 学生的选择题填涂读不出 | 该题**仍然有判定**（勾叉和分数都在），只是「你写的是什么」那一栏留白并说明 |
| 某题挂不上知识点 | 页面明说「这道题没挂上知识点」，不塞占位标签 |
| 一道题都没错 | 不编薄弱点，直接说「这次全对」 |
| 建议里没有题号 | 重生成一次；仍没有就只展示错题和官方解答，**不展示建议** |

## 探针结论（2026-08-08 实测）

**Ⓐ 读参考答案：过。** 拿老师给的第 1 页（`pages.normalize` 出的 1080×1441）跑一次，

## 探针结论（2026-08-10 实测，方舟 `doubao-seed-evolving`）

材料：老师给的 2 张手机截图 `20260807-234347/234408.jpeg`，各 1080×2337。
人工真值由我逐格看原图读出来，**并且用总分对过账**：逐题得分加起来正好等于
卷子上印的 `58.5`，所以下面拿来打分的那份真值本身是站得住的。

### Ⓢ 抠答题卡：几何就够

按行平均亮度找最长亮段 → 两张截图都是 `y=919..1669`（高 750）；按列平均亮度
在中点附近找最暗一列 → `x≈540`，劈成左右两页。**两张都精确命中。**

但同一套判据跑整页扫描件会**假阳性**（参考答案那 4 张整页都亮，照样切得出一条）。
几何只能回答「截图里答题卡在哪」，回答不了「这张是不是截图」，判据见 Ⓢ 那节。

### Ⓑ 读批改：分区读完胜整页读

| 切法 | 尺寸 | 耗时 | 非选作答 | 批改符号 | 得分标注 | 选择题填涂 |
|---|---|---|---|---|---|---|
| 两页一起喂 | 1080×750 | 213s | 好 | 好 | 丢 4 条 | **整块漏掉** |
| 一页原分辨率 | 540×750 | 235s | **10/10** | **10/10** | 8/10 | 0/8（老实说 `unreadable`） |
| 一页放大 2× | 1080×1500 | 337s | 10/10 | 10/10 | 7/10 | **0/8，而且编了 4 个** |
| **选择题块 ×3** | 1590×315 | **59s** | — | 8/8 | — | **8/8** |
| **得分块 ×3** | 1170×780 | **23s** | — | — | **8/8** | — |

三条结论：

1. **「不要放大」要改写成「不要**整张**放大」。** 整页放大 2× 并没有超时（337 秒
   回来了，上一次探针那个 600 秒是拿密排印刷的参考答案页测的，对答题卡不成立）——
   它的问题**比慢严重得多**：把「读不出来」变成了「编一个」。题 1-4 全答 `A`
   （真值 `D C C B`），题 6 把老师红笔写的正确答案 `B,C` 当成了学生的作答。
   原分辨率那一版老老实实回 `unreadable` + `conf: low`，反而是对的。
2. **裁小块 + 放大 + 说明版面的提示词 = 满分，还快 4 倍**（59+23 秒 vs 235 秒）。
   选择题那一段提示词写明了「左栏单选 1-4、右栏双选 5-8，形如 `01 [A][B][C][D]`，
   学生把选中的方括号涂黑」，并且**把「学生涂的」和「老师红笔写的」分成两个字段问**
   —— 合着问正是整页放大 2× 那一版搞混的地方。
3. **模型说 `conf: low` 的时候是可信的。** 8 道选择题在原分辨率下全部 `unreadable`
   + `low`，一个都没编。这条支持「读不出就说读不出」的设计，不用额外的兜底判据。
