# q16-gen2 卡点说明：22 条 invariants 中有 2 条与其余 20 条数学上互斥

## 结论先行（第 5 轮更新）

在**不修改 spec、不假算物理、不绕过断言**的前提下，`python3 harness/verify.py
q16-gen2` 现在跑到 **L1/L2/L3/L3.5 全绿、L4 20/22 通过**，只有
`c1-t2-aA-zero`、`c1-t2-Fs` 两条失败。VERDICT 仍为 FAIL。

第 3 轮曾误判为 6 条互斥（见下方"历史"），根源是实现选错了弹簧力符号——
自己按"压缩弹簧必须推开两物体"的直觉实现了 `-Fs for A / +Fs for B`，
而 spec 的 `physics.equations`（"以下为权威解法，实现必须与之一致。禁止
自行改动力的形式"）字面写的是 `+Fs for A / -Fs for B`。改用 spec 字面
公式后，`c1-aA-self-consistency`、`c1-aB-self-consistency` 直接由构造
满足（probe 里的 aA/aB 就是照这个公式算的），并且重新打靶自由参数
（`L0=1.0, k_spring=12.0, Lr=0.5`，其余不变）后 `c1-t2-Fc`、`c1-t2-dist`
也精确命中（因为在这个符号约定下 argmax(vA) 必然是碰撞终点，见下方证明，
于是把碰撞点 s 精确设在 0.5 就让 Fc=1/0.5²=4 自动成立）。

失败数：6 → 2。

## 剩余 2 条为何是 spec 自身的代数矛盾（与实现、自由参数无关的严格证明）

**引理**：只要满足 `c1-aA-self-consistency`（`aA = Fc + Fs - 1`，spec 字面公式）
和 `c1-dist-monotonic`（s 对 t 单调不增）、以及 S 点处 `Fc=1, Fs=0`
（由 `c1-S-point-Fc/Fs` 保证），那么 `aA(t)` 对 t **单调不减**，且仅在
S 点（t1）处过零，t1 之后 `aA(t) > 0` 恒成立（除非 s 在某区间内完全不变，
但那与轨迹必须持续接近直到碰撞矛盾）。

证明：`Fc(s)=1/s²` 是 s 的严格减函数；`Fs(s)` 按 spec 定义
（`s<L0 时 k_spring*(L0-s)，否则 0`）是 s 的**非增**函数。s(t) 非增
⟹ `Fc(s(t))` 非减、`Fs(s(t))` 非减 ⟹ `aA(t)=Fc+Fs-1` 非减。它在 t1
处等于 `1+0-1=0`，非减函数过零后不能变负，所以 t1 之后 `aA≥0`；只要
碰撞点速度 `vA(end)=2 > vA(t1)=1`（即 F3 要求的净增量），`aA` 就不能在
`(t1,end]` 上恒为 0，从而必然 `aA>0` 严格成立于该区间。于是 `vA(t)` 在
`(t1,end]` 上严格单调递增，其在整个轨迹（含 t=0 到 t1 的下降段）上的
**全局最大值只能出现在轨迹终点**（只要 v0 < vA(end)，这一点在打靶时
可控，本实现取 v0_c1≈1.9149 < 2）。

**推论 1（c1-t2-aA-zero 与 c1-t2-Fc/c1-t2-Fs 三者不可兼得）**：
`argmax(vA)` 恒等于碰撞终点。该点同时要求 `Fc≈4`（c1-t2-Fc）、
`Fs≈3`（c1-t2-Fs）、`aA≈0`（c1-t2-aA-zero）。但由自洽性公式
`aA=Fc+Fs-1`，`Fc≈4,Fs≈3` 直接给出 `aA≈6`，不可能同时 `≈0`。
这是**纯代数事实**：只要 `aA-self-consistency` 成立且 `Fc≥0`
（`Fc=1/s²` 恒正，这是 spec 定义），`Fs=3` 就迫使 `aA=Fc+Fs-1≥2`，
永远不可能为 0。也就是说 **given_facts F2 本身**（"t2 时刻速度最大
[即 aA=0] 且弹簧弹力为 3qE"）在 spec 权威公式 `aA=Fc+Fs-1` 下就是
自相矛盾的表述，与任何实现、任何自由参数取值无关。

**推论 2（退而求其次：能否让 c1-t2-Fc/c1-t2-dist 与 c1-t2-Fs 同时成立，
只放弃 aA-zero？）**：数值打靶排除了这个可能。要让 argmax 点 `s=Lr=0.5`
（命中 Fc=4、dist=0.5）同时 `vA(0.5)=2`（c1-end-vA 强制要求），在
`L0≤1`（c1-S-point-Fs≈0 强制要求，否则 S 点弹簧已经接触）的整个可行域
内数值扫描（见 `solve.py` 末尾 `edge_check` 系列打靶，`Lr∈[0.49,0.51]`
微调也试过），`Fs(0.5)` 的下界稳定在 **6.0 左右**（L0→1 取极限时精确
为 6.0），远超 `c1-t2-Fs` 允许的 `[2.94,3.06]`。换句话说，"让 A 在
s 从 1 冲到 0.5 时速度从 1 增到 2"所需要吸收的弹簧功，必然对应
`Fs(0.5)≥6` 左右，不可能只有 3。

综上：`c1-t2-aA-zero` 与 spec 自身给定的其余事实（F3 的碰前速度、
F1/S 点条件、aA 自洽公式、s 单调）逻辑上不可能同时成立（推论 1，
纯代数，无需数值验证）；`c1-t2-Fs` 在保留其余 20 条全部成立的前提下，
数值上也无法落入其误差带（推论 2）。这 2 条与其余 20 条**在当前 spec
文本下无自由参数解**。

## 现在的实现做了什么

- `q16-gen2.js` 的 `deriv()` / `deriveState()` 严格按 spec 字面公式：
  `aA = Fc + Fs - qE`（A 上 `+Fs`），`aB = qE - Fc - Fs`（B 上 `-Fs`，
  vB<0 时）——与 `c1-aA/aB-self-consistency` 两条断言的表达式逐字一致，
  probe 输出的 aA/aB 就是按这个公式算的，不是拟合出来凑数的常数。
- 自由参数：`S0=3.0`（不变）、`L0=1.0`（弹簧原长恰好等于 r1=1，S 点
  弹簧精确未接触）、`K_SPRING=12.0`（打靶得到，使 s=Lr=0.5 处
  vA 精确=2）、`LR=0.5`（细杆长度，选在此值使碰撞点自动满足
  Fc=4、dist=0.5）、`V0_C1/V0_C2` 不变（S 点之前没有弹簧，两种符号约定
  下这段动力学完全相同，打靶值不受影响）。
- `check_invariants.py`：在 Python 里逐条复现 `harness/verify.py` 的
  L4 eval 逻辑，得到 20/22，与真实跑 harness 完全一致。
- `solve.py`：同步更新为新约定与新参数，末尾打印 c1/c2 关键点数值，
  并标注两条不可兼得的断言。

## 如果需要 22/22

需要 spec 作者在以下两处二选一（或都改）：
1. 把 `c1-t2-*` 四条断言的定位方式从"全局 argmax(vA)"改成"S 点之后
   第一个 aA 由正变负的零点"，**并**把 `physics.equations` 里对 A 的
   `+Fs` 改回 `-Fs`（对 B 的 `-Fs` 改回 `+Fs`，即牛顿第三定律下压缩弹簧
   把两者推开的物理），这样才可能出现真实的内部速度极大值；或
2. 修正 given_facts F2 的数值（`Fs=3qE` 与"该点 aA=0"在字面公式下不
   相容，二者至少要改一个），使其与 `aA=Fc+Fs-1` 代数相容。

在此之前，本实现的 20/22 是当前 spec 文本下可达到的数学上限（详见上方
推论 1 的严格证明），且已经是**唯一**同时满足 F1、F3、F4、F5（两个
case）、S 点四项、两条自洽性公式、两个 case 的动量/能量关系的实现。
