## 1. 解参数的思路

### 1.1 先把问题化成一个函数 g(d)

无量纲化后（qE = 1，m = 1，长度单位 d₁）：

```
F_s(d) = k_s (L_s − d)  当 d < L_s，否则 0
g(d) ≡ a_A = 1 + 1/d² − 2 − F_s(d) = 1/d² − 1 − F_s(d)
```

spec 里 F4 已经点明 B 起动后 a_B 与 a_A 同式，所以全过程只需要这**一个**函数 g。

### 1.2 F1 定 "L_s < 1"

v_A 在 d = 1 取极小 ⟹ g(1) = 0。若 L_s > 1 则 g(1) = −k_s(L_s−1) ≠ 0；
若 L_s = 1，则 d 从 1 往下时 g′(1) = −2 + k_s > 0 会让 g 立刻变负，d = 1 就不是极小点而是拐点。
**必须 L_s < 1**，这样 d ∈ (L_s, 1) 上 g = 1/d² − 1 > 0（过 S 后 A 先加速），d > 1 上 g < 0（逼近 S 时减速）。

### 1.3 F2 定 k_s(L_s − 0.5) = 3，并逼出 k_s ≥ 16

极大值处 g = 0 且 F_s = 3 ⟹ 1/d² − 1 − 3 = 0 ⟹ **d = 0.5**，同时 `k_s (L_s − 0.5) = 3`。

**这里是本题最大的坑**（也就是任务提示里说的"加速度在某个区间意外变号"）：
只要求 g(0.5) = 0 是不够的，还必须保证 0.5 真是"由加速转减速"的那个零点。
g′(d) = −2/d³ + k_s 在 d\* = (2/k_s)^(1/3) 处取到 g 的极小值。
若 d\* > 0.5，则 g(d\*) < g(0.5) = 0，于是 (0.5, L_s) 内会冒出一段 g < 0，
v_A 在到达 d = 0.5 之前就先冲高再回落 —— 与题意矛盾，`c1-d-at-vmax` / `c1-vmax-inside` 会直接打回。

```
d* ≤ 0.5  ⟺  k_s ≥ 16
```

### 1.4 g 的第二个零点定 L_r 的下界

d 更小时 1/d² 又压过弹簧项，g 会重新变正。把 g(d) = 0 化成三次方程

```
k_s d³ − (4 + k_s/2) d² + 1 = 0
```

已知 d = 0.5 是根，因式分解得 `k_s d² − 4d − 2 = 0`，正根

```
d₂ = (2 + √(4 + 2k_s)) / k_s
```

d < d₂ 时 g > 0、v_A 重新上升。**细杆必须在这之前碰到 B**，否则 argmax(vA) 会跑到过程末端。
所以 `d₂ < L_r < 0.5`。

### 1.5 F3 把 v₁ 和 L_r 绑在一起

B 起动后 a_A ≡ a_B，令 S = v_A + v_B = −ḋ，则 S·dS/dd = −2g(d)，积分得

```
S(d)² = S(1)² + 4 J(d),      J(d) ≡ ∫_d^1 g(x) dx
```

J 有闭式（这一步让整个求解不需要数值求根）：

```
J(d) = 1/d + d − 2 − (k_s/2)(L_s − d)²   (d < L_s)
J(d) = 1/d + d − 2                        (d ≥ L_s)
```

碰撞瞬间要求 v_A = 2v₁、v_B = v₁ ⟹ S = 3v₁ ⟹ 9v₁² = v₁² + 4J(L_r) ⟹

```
J(L_r) = 2 v₁²        即     v₁ = √( J(L_r) / 2 )
```

注意：这条**只是把 v₁ 和 L_r 绑起来**，并没有把两者都定死，仍剩一个自由度。
d₀ 也自由，初速度由 d ≥ 1 段的能量关系给出：`v_A(d)² = v₁² + 2(d + 1/d − 2)`。

### 1.6 F5 是推论，不构成额外约束

情形②只是把 S(1) 从 v₁ 换成 2v₁，同一个 J(L_r) = 2v₁²：

```
S(L_r)² = 4v₁² + 4·2v₁² = 12v₁²  ⟹  S = 2√3 v₁
v_A = (S + 2v₁)/2 = (√3+1)v₁ ,  v_B = (S − 2v₁)/2 = (√3−1)v₁
```

F1–F3 自洽了，F5 自动成立。所以 c2 的三条断言不需要额外调参。

### 1.7 剩下的自由度用"断言余量"定（solve.py 的网格搜索）

`solve.py` 对 (k_s, L_r, d₀) 做网格搜索，每组参数都**完整正演 + 按 401 点采样 +
用与 verify.py 完全相同的表达式求值全部 16 条 invariant**，再按"最坏情况余量"打分：

* 对齐类（`c1-d-at-vmax` / `c1-a-zero-at-extrema` / `c1-Fs-at-vmax`）不吃采样点碰巧对齐的运气，
  一律按 d = 0.5 附近的**半个采样步长**估上界：|Δd|/2、|k_s−16|·|Δd|/2、k_s·|Δd|/2。
* 结构类：v_max − v_end、v_max − v_min、v_max − v₀。

搜索里跳出来**第二个坑**：`d₀ 不能太大`。
v₀ = √(v₁² + 2(d₀ + 1/d₀ − 2)) 随 d₀ 单调增，d₀ ≥ 1.8 时 v₀ 反而超过 d = 0.5 处的 v_max，
于是 `argmax(vA)` 落到样本 0，`c1-vmax-inside` / `c1-d-at-vmax` / `c1-Fs-at-vmax` /
`c1-a-zero-at-extrema` / `c2-same-geometry` 五条一起挂（网格里表现为 11/16）。
我一开始手算时默认取 d₀ = 2.0，正是这一组 —— 幸好搜索把它筛掉了。

### 1.8 最终参数

| 量 | 值 | 来源 |
|---|---|---|
| 劲度 k_s | **30** | 自由度，取 ≥16 且余量最好的圆整值 |
| 弹簧原长 L_s | **0.6** | = 0.5 + 3/k_s（F2） |
| 细杆长 L_r | **0.4** | 自由度，须 > d₂ = 1/3（本组余量 0.0667） |
| 弹簧自然长度 | **0.2** | = L_s − L_r（杆端接弹簧，弹簧压到零长时杆碰 B） |
| 初始间距 d₀ | **1.3** | 自由度，须使 v₀ < v_max |
| **v₁** | **√0.15 = 0.387298334621** | = √(J(L_r)/2)，J(0.4) = 0.3 |
| 情形① 初速度 v₀ | **0.537086155530** | = √(v₁² + 2(d₀ + 1/d₀ − 2)) |
| 情形② 初速度 v₀ | **0.859337848847** | = √(4v₁² + 2(d₀ + 1/d₀ − 2)) |

派生：g 的极小点 d\* = (2/30)^(1/3) = 0.4055 < 0.5 ✓；第二零点 d₂ = 1/3 < L_r ✓；
碰撞瞬间 a_A = −0.75（明显 < 0，不卡在拐点上）；T₁ = 1.5440，T₂ = 0.9535。

校验：情形① 末态 v_A/v₁ = 2.000000、v_B/v₁ = 1.000000；
情形② 末态 v_A/v₁ = 2.732051 = √3+1、v_B/v₁ = 0.732051 = √3−1。

JS 里只内嵌 k_s / L_s / L_r / d₀ 四个常数，v₁ 和两个初速度都是 JS 现算，
轨迹是用 RK4（dt = 4×10⁻⁴，事件处二分收缩步长精确落到 d = 1 和 d = L_r）真跑出来的，
`probe` 只是在这条轨迹上按 u·T 线性插值。

## 3. 最难满足的断言

**`c1-a-zero-at-extrema`（在 v_A 极大处 |a_A| ≤ 0.12）最难。**

原因是它同时被两件事夹住：

* g′(0.5) = k_s − 16。为了避开 1.3 节的陷阱必须 k_s ≥ 16，可 k_s 一大，
  a_A 在 d = 0.5 附近就变得很陡：偏离 0.5 一点点，|a_A| 就被放大 (k_s−16) 倍。
  容差 0.12 折算成"argmax 样本离 d = 0.5 的允许距离"只有 `0.12/(k_s−16)`，
  k_s = 30 时是 0.0086，比 `c1-d-at-vmax` 的 0.02 还紧一倍多。
* 而 argmax 落在哪，取决于 401 个**等时**样本在 d = 0.5 附近的疏密，
  也就是 |ḋ|·T/400。T 又由 d₀ 决定 —— 于是 k_s 和 d₀ 被耦合到了一起：
  k_s 大要求采样密，采样密要求 T 小，T 小要求 d₀ 小，d₀ 小又逼近 1.7 节的 v₀ 陷阱。

最终 k_s = 30 / d₀ = 1.3 时 d = 0.5 附近相邻样本 Δd = 0.0048，最坏偏差 0.0024，
|a_A| 上界 14 × 0.0024 = 0.034，对 0.12 有约 3.5 倍余量。

次难的是 `c1-vmax-inside`：它是布尔断言、没有容差，v_max − v_end 只有 0.0415，
v_max − v₀ 只有 0.279，两边都不能踩过界。

（`c1-momentum` / `c2-momentum` 反而是最容易的：因为 B 起动后 a_A 与 a_B 同式，
RK4 给 v_A 和 v_B 的增量逐级完全相同，v_A − v_B 在浮点意义上就是严格常量，实测残差 0.0。）

## 4. spec 里让我走弯路 / 建议改进的地方

按对我影响从大到小排：

1. **`free_parameters` 只说"必须自洽"，没说清自洽约束一共有几条、还剩几个自由度。**
   实际上 F1–F3 只给出 2 个方程（`k_s(L_s−0.5) = 3` 和 `J(L_r) = 2v₁²`），
   却有 5 个未知量（L_s, k_s, L_r, d₀, v₀），剩 3 个自由度；而真正会卡人的
   `k_s ≥ 16`、`L_r > d₂`、`v₀ < v_max` 三条全是**不等式**，一条都没写进 spec。
   任务 prompt 里的"历史教训：加速度在某个区间意外变号"其实就是在暗示 `k_s ≥ 16`，
   但这句提示在 prompt 里而不在 spec 里 —— 如果只发 spec，实现方大概率会在这里翻车。
   建议在 `free_parameters` 里补一句"注意 g(d) 在 (L_r, 1) 上除 d=0.5 外不应再变号"。

2. **`sample_points: 401` 没说 u 该怎么参数化，但断言对采样密度极度敏感。**
   `c1-a-zero-at-extrema` 能不能过，取决于"u 是等时还是等 d"。
   我选了等时（对动画最自然，`process_endpoints` 的措辞也偏向时间），
   于是采样密度反过来约束了 d₀ 和 k_s（见第 3 节）。
   如果换成等 d 参数化，同样一组物理参数的余量会宽好几倍。
   建议 spec 明确 "u 线性于物理时间" 或 "u 线性于 d"，否则不同实现的难度差异很大。

3. **`process_endpoints` 说 "u = 0 对应 A 从初始间距 d₀ 出发"，但没说 d₀ 也算自由参数的一部分。**
   `free_parameters` 里列了 d₀，两处要对着读才知道 u=0 的位置是我自己定的。
   而 d₀ 恰恰是第二个陷阱的来源（v₀ 反超 v_max）。建议在 `process_endpoints` 里直接提醒
   "d₀ 的选取会影响 argmax(vA) 落点"。

4. **几何没定义：细杆和弹簧到底怎么接。**
   spec 只说"弹簧原长 L_s、d < L_s 时接触"和"d = L_r 时细杆碰 B"，
   物理上完全够用，但画图时必须自己补一句"弹簧接在杆端，自然长度 = L_s − L_r，
   压到零长时杆正好碰 B"，并因此推出隐含约束 `L_r < L_s`。
   这条约束在 spec 里一个字都没有。建议在 `definitions` 里加一行。

5. **`probe_key_meaning` 里 `vB` 写的是"B 的速率，向左运动取正值"，
   而 `vA` 写的是"向右为正"，两者符号约定相反。**
   这本身是对的（F4 的 v_A − v_B = const 只有在这套约定下才成立），
   但两个键紧挨着、方向约定相反，很容易看漏。
   建议把 `c1-momentum` 的 `why` 里那句"电场力与摩擦力两两抵消"改成
   "注意 v_B 取向左为正，故 v_A − v_B 才是守恒量"。

6. 小瑕疵：`c1-momentum` 的 `why` 写"电场力与摩擦力两两抵合"，
   但真正让 a_A ≡ a_B 的是 **A 和 B 各自的 (电场力 + 摩擦力) 恰好都等于 1 − 2 = −1**，
   库仑力和弹力则是靠"大小相等、对 A 和对 B 的符号约定同向"抵掉的。
   照 `why` 的字面理解容易以为只要电场力和摩擦力抵消就行。

（`disclosures` 那条要求很好 —— 强制在图里写明读数是无量纲值，确实是这类图最容易误导人的地方。）
